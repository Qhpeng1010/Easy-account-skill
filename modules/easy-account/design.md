# 易通账 Easy Account 设计规范

> 来源：Figma 文件「易通账 Easy Account业务页面」  
> 文件 Key：`ZWbmQGeL2RB4Ib9aYVpsl4`  
> 提取范围：Color、Fonts、Shadows 基础规范画板，以及查询列表、详情、弹窗表单、抽屉详情、整页表单等 9 个业务页面。  
> 本文只沉淀可复用的视觉、布局、组件和页面模式，不包含具体业务字段与业务流程。

## 1. 设计定位

易通账采用清晰、克制、高信息密度的 PC 端管理后台风格。

- 以白色内容容器和浅灰页面背景建立层级。
- 以蓝色作为品牌色和主要操作色。
- 强调结构清楚、操作直接、状态可识别。
- 页面优先使用成熟组件模式，不依赖装饰性视觉。
- 适用于列表查询、账户管理、资料录入、信息详情和状态处理等后台场景。

## 3. 字体规范

### 3.1 字体家族

```css
font-family:
  "PingFang SC",
  "Nunito Sans",
  "Helvetica Neue",
  Arial,
  sans-serif;
```

- 中文：`PingFang SC`
- 英文与数字：`Nunito Sans`
- 代码或等宽内容：`Menlo`
- 常用字重：Regular、Medium
- 仅在需要突出正文或表头时使用 SemiBold / Bold，避免大面积加粗。

### 3.2 中文字号

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 辅助文案 | `12 / 20` | Regular 或 Medium |
| 正文-常规-小 | `13 / 20` | Regular 或 Medium |
| 正文-常规-大 | `14 / 22` | Regular 或 Medium |
| 段落正文 | `14 / 22` | Regular |
| 标题-小 | `16 / 24` | Medium |
| 标题-中 | `20 / 28` | Medium |
| 标题-大 | `24 / 32` | Medium |
| 运营标题-小 | `36 / 44` | Regular 或 Medium |
| 运营标题-中 | `48 / 56` | Regular 或 Medium |
| 运营标题-大 | `56 / 64` | Regular 或 Medium |

### 3.3 英文与数字字号

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 最小文本 | `10 / 20` | Regular 或 Medium |
| 辅助、次要、水印文本 | `12 / 20` | Regular 或 Medium |
| 正文-常规-小 | `13 / 20` | Regular 或 Medium |
| 正文-常规-大 | `14 / 22` | Regular 或 Medium |
| 正文强调 | `14 / 22` | Bold |
| 标题-小 | `16 / 24` | Medium |
| 标题-中 | `20 / 28` | Medium |
| 标题-大 | `24 / 32` | Medium |
| 运营标题 | `36 / 44`、`48 / 56`、`56 / 64` | Regular 或 Medium |

### 3.4 使用规则

- 默认页面正文使用 `14px / 22px`。
- 表单标签、导航和表格正文以 `14px` 为主。
- 辅助说明、表格副信息、时间和弱提示使用 `12px / 20px`。
- 页面标题通常使用 `20px / 28px`、Medium。
- 模块标题通常使用 `16px / 24px`、Medium。
- 统计数字可使用 `24px / 32px`、Medium。
- 默认字间距为 `0`。
- 不用仅靠字号区分层级，应结合字重、颜色和间距。

## 4. 间距与圆角

### 4.1 间距体系

采用以 4px 为基础单位的间距体系。

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `space-1` | `4px` | 图标微间距、紧凑菜单间隔 |
| `space-2` | `8px` | 图标与文字、紧凑元素 |
| `space-3` | `12px` | 小组件内部间距 |
| `space-4` | `16px` | 卡片间距、表单行列间距 |
| `space-5` | `20px` | 页面内容边距、卡片内边距 |
| `space-6` | `24px` | 模块间距 |
| `space-8` | `32px` | 大区块间距 |

高频组合：

- 页面内容区外边距：`20px`
- 卡片之间：`16px`
- 卡片内边距：`20px`
- 图标与文字：`8px`
- 按钮之间：`8px`
- 表单标签与控件：`8px`
- 两列或四列表单列间距：`16px`

### 4.2 圆角

| Token | 值 | 使用场景 |
| --- | --- | --- |
| `radius-small` | `2px` | 标签、紧凑状态块 |
| `radius-default` | `4px` | 输入框、按钮、卡片、Tab |
| `radius-medium` | `8px` | 弹窗、较大浮层 |
| `radius-round` | `100px` | Avatar、圆形按钮、胶囊状态 |

默认原则：

- 表单控件、按钮、卡片优先使用 `4px`。
- 弹窗外框可使用 `8px`。
- 不混用过多圆角等级。

## 5. 阴影

### 5.1 浮层阴影

```css
--shadow-dropdown-1: 0 4px 10px rgba(0, 0, 0, 0.10);
--shadow-dropdown-2: 0 8px 20px rgba(0, 0, 0, 0.10);
--shadow-backtop: 0 4px 10px rgba(0, 0, 0, 0.10);
```

方向性阴影：

```css
--shadow-left: -2px 0 5px rgba(0, 0, 0, 0.10);
--shadow-right: 2px 0 5px rgba(0, 0, 0, 0.10);
--shadow-up-left: -2px -2px 5px rgba(0, 0, 0, 0.10);
--shadow-up-right: 2px -2px 5px rgba(0, 0, 0, 0.10);
--shadow-down-left: -2px 2px 5px rgba(0, 0, 0, 0.10);
--shadow-down-right: 2px 2px 5px rgba(0, 0, 0, 0.10);
```

使用原则：

- 普通卡片不使用阴影，以背景和边界建立层级。
- Dropdown、Popover、二级浮层使用阴影。
- 弹窗通过遮罩和边界建立层级，不叠加重阴影。
- Tabs 的强调边可通过品牌色内阴影或底边实现。

## 6. PC 端页面框架

### 6.1 基准画布

- 设计基准宽度：`1440px`
- 页面最小推荐宽度：`1280px`
- 内容随窗口宽度自适应。
- 业务内容区不应被固定画布宽度限制，但应保留稳定的边距和栅格。

### 6.2 顶部导航

| 属性 | 规范 |
| --- | --- |
| 高度 | `48px` |
| 背景 | `#FFFFFF` |
| 底边 | `1px solid #E5E6EB` |
| Logo 区 | 左侧固定区域 |
| 一级导航 | 横向排列，选中项使用品牌蓝 |
| 右侧工具区 | 通知、搜索、账户信息 |

顶部导航应始终保持单行，一级导航不换行。

### 6.3 左侧导航

| 属性 | 规范 |
| --- | --- |
| 宽度 | `220px` |
| 起始位置 | 顶部导航下方 |
| 菜单左右边距 | `8px` |
| 菜单内容宽度 | `204px` |
| 菜单项高度 | `40px` |
| 一级菜单间距 | `4px` |
| 图标尺寸 | `18px` |
| 收起区高度 | `48px` |

状态规则：

- 默认文字使用 `color-text-2`。
- 当前一级菜单图标和文字使用品牌色。
- 当前二级菜单使用浅灰或浅蓝背景，文字使用品牌色。
- 可展开菜单右侧使用方向图标。
- 导航收起后内容区自动扩展。

### 6.4 内容区

```text
顶部导航：48
左侧导航：220
内容起点：x = 240
内容区左右边距：20
内容区宽度：视窗宽度 - 220 - 40
```

- 页面背景使用 `#F7F8FA`。
- 内容卡片背景使用 `#FFFFFF`。
- 内容卡片间距使用 `16px`。
- 内容区顶部通常先放面包屑或返回入口，再放页面主体。
- 卡片默认内边距为 `20px`。
- 页面底部版权信息使用 `12px` 次要文字。

## 7. 栅格与表单布局

### 7.1 查询条件

- 宽屏查询区优先使用四列栅格。
- 每个字段由“标签 + 控件”纵向组成。
- 标签与控件间距 `8px`。
- 列间距 `16px`。
- 行间距 `16px`。
- 查询与重置按钮放在最后一行右侧。
- 主按钮在右，次按钮在左。
- 查询条件过多时应支持展开 / 收起，不无限增加首屏高度。

### 7.2 弹窗表单

- 默认采用两列布局。
- 相关字段同组排列。
- 单选项、上传项、长文本可独占整行。
- 表单区使用分组标题区隔。
- 必填项在标签后使用红色 `*`。
- 帮助说明放在控件下方，使用 `12px` 与 `color-text-3`。

### 7.3 整页表单

- 用于字段较多、流程较长或包含上传材料的任务。
- 页面内容按业务语义拆为多张白色卡片。
- 每张卡片顶部使用模块标题。
- 底部操作区固定在视口底部，避免长页面提交入口不可见。
- 固定操作区需有白色背景和顶部分隔线。

## 8. 组件规范

### 8.1 Button

建议高度：

- 默认按钮：`32px`
- 重要操作或弹窗底部按钮：`36px`
- 紧凑按钮：`28px`

类型：

- Primary：品牌蓝背景、白色文字。
- Secondary：浅灰背景、深色文字。
- Outline：白色背景、品牌色描边与文字。
- Text / Link：无背景，使用品牌蓝文字。
- Danger：仅用于高风险、不可逆操作。

规则：

- 同一区域只保留一个 Primary。
- 按钮文字使用 `14px` Regular / Medium。
- 图标与文字间距 `8px`。
- 按钮组间距 `8px`。
- 禁用状态降低对比度，但仍需保留边界。

### 8.2 Input / Select / DatePicker

| 属性 | 规范 |
| --- | --- |
| 默认高度 | `32px` |
| 默认圆角 | `4px` |
| 默认边框 | `#E5E6EB` |
| Hover 边框 | `#C9CDD4` |
| Focus 边框 | `#1E75FF` |
| Placeholder | `#C9CDD4` |
| 禁用背景 | `#F2F3F5` |

规则：

- 文字左右内边距通常为 `12px`。
- 前后图标保持 `14–16px`。
- 错误态使用 Danger 色，并在控件下方提供错误说明。
- 不仅依赖边框颜色表达错误，应同时提供文字信息。

### 8.3 Radio / Checkbox

- 默认控件尺寸约 `14px`。
- 选中状态使用品牌蓝。
- 标签与控件间距 `8px`。
- 同组横向选项间距建议 `24px`。
- 禁用状态降低对比度并保持可识别。

### 8.4 Tabs

文件中存在两种主要形式：

1. 页面级圆角 Tab：用于业务对象分类或详情分区。
2. 卡片内下划线 Tab：用于列表分类与数量切换。

规则：

- 选中文字使用品牌蓝。
- 页面级 Tab 可使用浅灰选中背景。
- 列表型 Tab 使用品牌色底边。
- Tab 数量显示在标题后，如“全部门店(12)”。
- 不将高风险操作放入 Tab。
- 结果列表使用分类 Tabs 时，保留 Ant Design Tabs 默认高度；Tabs 上方预留 `8px`，下方保留默认 `16px` 间距，总占位高度为 `70px`。
- 结果列表 Tabs 不显示导航底部的灰色分割线，只保留选中态品牌色底边。

### 8.5 Table

| 属性 | 规范 |
| --- | --- |
| 表头背景 | `#F2F3F5` |
| 表头文字 | `#1D2129`，14px Medium |
| 表格正文 | `#1D2129`，14px Regular |
| 辅助信息 | `#86909C`，12px Regular |
| 分隔线 | `#E5E6EB` |
| 操作文字 | 品牌蓝 |

规则：

- 表头高度约 `40–50px`。
- 正文行根据内容采用单行或“主信息 + 副信息”双行结构。
- 操作列固定在右侧，主要操作直接展示，低频操作收进“更多”。
- 状态可使用圆点、浅色标签或文字组合表达。
- 表格底部分左右分布分页：左侧显示结果总数，右侧放 Ant Design Pagination 的页码、页大小切换和更多分页控件。
- 空数据状态保留表头，并在表体中居中展示空状态。
- 横向字段较多时优先优化字段优先级，再考虑横向滚动。

### 8.6 Pagination

- 当前页使用浅蓝背景或品牌色强调。
- 分页容器左右分布，左侧固定显示总条数，右侧提供页码、翻页图标和每页条数选择。
- 页码、翻页图标和每页条数保持同一基线；窄屏时左右区域纵向堆叠，不能互相遮挡。

### 8.7 Tag / Status

- 成功：绿色文字或圆点 + 浅绿背景。
- 处理中 / 待处理：蓝色文字或圆点 + 浅蓝背景。
- 警告 / 冻结：橙色文字或圆点 + 浅橙背景。
- 失败 / 驳回：红色文字或圆点 + 浅红背景。
- 未绑定 / 未开通：中性灰。

状态不能只使用颜色表达，应同时显示明确状态文案。

### 8.8 Card

- 背景：`#FFFFFF`
- 圆角：`4px`
- 内边距：`20px`
- 默认不使用阴影。
- 同层卡片之间保持 `16px` 间距。
- 模块标题使用 `16px / 24px` Medium。
- 标题右侧可放次级操作链接。

### 8.9 Modal

样例弹窗宽度约 `720px`，适合两列表单。

- 遮罩：黑色，约 50% 透明度。
- 外框：白色背景，`8px` 圆角。
- Header：标题左对齐，关闭图标右对齐。
- Header 与 Footer 使用分隔线。
- Body 可滚动，Header 和 Footer 固定。
- Footer 操作右对齐，取消在左、提交在右。
- 表单较长时，不增加弹窗高度到超出视口。

### 8.10 Drawer

- 从右侧进入。
- 样例宽度约为视口的 50%，适合详情与轻量编辑。
- Header 固定，内容滚动，Footer 固定。
- 详情内容可通过 Tabs 分区。
- 抽屉内表格应适配抽屉宽度，不照搬整页表格列数。
- 关闭入口位于右上角。

### 8.11 Empty State

- 空状态位于容器或表格主体中心。
- 使用轻量插图或空盒图标。
- 标题简短明确，如“暂无数据”。
- 如有恢复路径，可提供一个主要操作或链接。
- 不使用大面积高饱和插画抢占业务信息。

### 8.12 Upload

- 上传区域使用浅色虚线边框。
- 支持点击上传。
- 图片上传应提供示例和格式说明。
- 上传后的预览应支持查看、更换或删除。
- 错误信息放在上传区域附近，不使用只在页面顶部出现的笼统提示。

## 9. 页面模板

### 9.1 查询列表页

结构顺序：

1. 全局顶部导航
2. 左侧导航
3. 面包屑
4. 可选的页面级 Tabs
5. 查询条件卡片
6. 列表卡片
7. 列表顶部分类 Tabs 与工具按钮
8. Table
9. Pagination

约束：

- 查询区和列表区必须拆为独立卡片。
- 查询按钮组靠右。
- 列表主要操作放在列表卡片右上角。
- 列表状态使用统一状态语言。

### 9.2 信息详情页

结构顺序：

1. 面包屑或返回入口
2. 页面标题卡片或对象摘要
3. 基础信息卡片
4. 业务分组卡片
5. 可选的关联列表

约束：

- 描述信息建议使用 2–3 列布局。
- 标签使用次要文字色，值使用主文字色。
- 分组之间使用卡片或分隔线。
- 详情页主要用于阅读，编辑操作应有明确入口，不直接把所有值做成输入框。

### 9.3 对象概览页

适用于品牌、账户等对象。

- 左侧可放头像或 Logo。
- 中部放关键身份信息。
- 右侧放状态、编号、日期等信息。
- 关键数据可拆成 3–4 个统计项。
- 后续模块使用卡片纵向排列。

### 9.4 弹窗表单

适用于字段量中等、无需离开当前上下文的新增或编辑任务。

- 两列表单。
- 分组标题。
- 固定 Header / Footer。
- 超长表单改用整页表单，不继续加高弹窗。

### 9.5 抽屉详情

适用于从列表快速查看对象信息。

- 不打断列表上下文。
- 顶部可使用 Tabs。
- 底部保留取消 / 提交，仅在抽屉可编辑时出现。
- 信息量过大或流程复杂时跳转整页。

### 9.6 整页表单

适用于开户、认证、材料上传和多模块录入。

- 返回入口位于内容区顶部。
- 每个语义模块单独成卡片。
- 表单字段对齐，必填项明确。
- 页面底部固定操作区。

## 10. 交互状态

所有可交互组件至少包含：

- Default
- Hover
- Active / Pressed
- Focus
- Disabled
- Loading
- Error（表单组件）

通用规则：

- Hover 只用于增强可感知性，不改变布局尺寸。
- Focus 必须提供清晰可见的品牌色描边。
- Loading 时阻止重复提交。
- Disabled 不能仅降低透明度到不可读。
- 删除、解绑、驳回等高风险操作需要二次确认。
- 成功反馈应说明结果，失败反馈应说明原因和下一步。

## 11. 响应式与自适应

本设计以桌面端为主。

- `≥ 1440px`：保持四列查询表单和完整表格。
- `1280–1439px`：压缩内容列宽，保留导航与核心操作。
- `< 1280px`：允许表格横向滚动；查询区从四列降为两列。
- 左侧导航收起后，内容区自动扩展。
- 弹窗和抽屉高度不得超过视口，内容区独立滚动。
- 固定底部操作区不得遮挡表单最后一项。

---

## 12. 可访问性

- 正文与背景对比度不低于 WCAG AA。
- 正文优先使用 `color-text-1` 或 `color-text-2`。
- 次要文字不应在小字号下使用过浅颜色。
- 状态必须同时有颜色和文字。
- Icon Button 必须提供可识别名称或 Tooltip。
- 键盘焦点必须可见。
- 表单错误应与具体字段关联。
- Placeholder 不能替代表单标签。
- 点击区域建议不小于 `32 × 32px`。

---

## 13. 图标与插图

- 图标采用简洁线性风格，常用尺寸为 `14px`、`16px`、`18px`、`20px`、`24px`。
- 同一操作区的图标保持统一线宽和视觉尺寸。
- 图标默认使用 `color-text-2`，激活后使用品牌色。
- 不使用 Emoji 代替功能图标。
- 空状态和上传示例可使用轻量插图，但不能改变后台产品的克制风格。

---

## 14. AI 页面生成约束

生成易通账页面时必须遵循：

1. 使用 `1440px` PC 管理后台骨架。
2. 顶部导航高度固定为 `48px`。
3. 展开态左侧导航宽度固定为 `220px`。
4. 内容区使用浅灰背景，卡片使用白色背景。
5. 页面内容外边距为 `20px`，卡片间距为 `16px`。
6. 主色固定为 `#1E75FF`。
7. 中文使用 PingFang SC，英文和数字优先使用 Nunito Sans。
8. 默认正文为 `14px / 22px`。
9. 输入框、选择器和默认按钮高度为 `32px`。
10. 默认圆角为 `4px`，弹窗圆角为 `8px`。
11. 普通卡片不使用阴影。
12. 查询列表页必须拆分查询卡片与列表卡片。
13. 查询条件宽屏使用四列，弹窗表单使用两列。
14. 表格表头使用 `#F2F3F5`，分隔线使用 `#E5E6EB`。
15. 主要操作使用 Primary，次要操作使用 Secondary、Outline 或 Link。
16. 同一区域只能出现一个 Primary。
17. 状态同时使用颜色和文案，不允许只用颜色。
18. 空数据时保留结构，并显示标准空状态。
19. 长表单优先使用整页表单和固定底部操作区。
20. 不重新发明视觉语言，不引入与现有规范冲突的渐变、重阴影、大圆角或装饰性字体。
