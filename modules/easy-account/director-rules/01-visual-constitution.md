# 易账通视觉宪法

## 产品气质

**EA-VIS-001** 易账通是清晰、克制、高信息密度的账户与账务管理后台。页面必须优先支持账户核对、账务处理和风险判断，不能做成营销页、装饰性数据大屏或大留白展示页。

## 色彩

**EA-VIS-002** 品牌主色与主要操作色为 `#1E75FF`，Hover 为 `#4B91FF`，Active 为 `#185ECC`，选中背景为 `#EBF1FF`。主色只用于唯一主操作、链接和选中态，不可作为大面积装饰色。

**EA-VIS-003** 页面背景为 `#F7F8FA`，业务面为 `#FFFFFF`，默认边框为 `#E5E6EB`。成功、警告和危险分别使用 `#00B42A`、`#FF7D00` 和 `#F53F3F`，并始终配合中文状态文案；状态不能只依赖颜色传达。

## 字体与密度

**EA-VIS-004** 中文优先使用 `PingFang SC`，英文和数字使用 `Nunito Sans`，回退到 `Helvetica Neue`、Arial。正文为 `14px/22px`，辅助信息为 `12px/20px`，模块标题为 `16px/24px`，页面标题为 `20px/28px`。默认字间距为 `0`，不使用 Hero 级标题或营销式排版。

**EA-VIS-005** 以 `4px` 为间距基准。页面内容边距为 `20px`，同层模块间距为 `16px`，业务面内边距为 `20px`，控件间距为 `8px`。查询列表优先保证信息密度、稳定对齐和可扫描性，不得用装饰性留白挤压数据区。

## 间距、圆角与表面

**EA-VIS-006** 灰色页面背景与白色业务面必须形成明确层级。全局按钮和有外框的表单交互控件统一使用 `6px` 圆角，包括 Input、InputNumber、Select、DatePicker、RangePicker、Textarea、TreeSelect、上传触发按钮及其校验状态外框；不得让组件库默认 `4px` 圆角混入同一页面。业务模块继续使用页面方案规定的 `8px` 圆角且无阴影，状态 Tag、Radio、Checkbox、Switch、圆形图标按钮和弹窗等具有独立语义或几何的组件保留各自规则；弹窗使用 `12px` 圆角和轻遮罩，整体在视口内水平、垂直居中，宽度不得小于 `480px` 或大于 `720px`，高度不得超过视口高度的 `80%`，超出时只允许内容区滚动。Modal 和 Drawer 的 Header 左上角必须显示非空的任务标题，标题优先使用表单明确声明的 `title`，缺失时必须回退到触发操作的 `label`，不得渲染无标题的空 Header。弹窗标题与正文之间必须额外保留 `20px` 上间距。不得嵌套装饰性卡片，也不得用阴影替代结构分组。

## 组件

**EA-VIS-007** 必须使用真实的 Ant Design 组件。页面不得用手写 HTML 模仿输入框、表格、下拉、抽屉、弹窗、分页、统计或结果页。易账通内所有以“标题 + 指标值”呈现的整体统计和对象概览项统一使用 Ant Design 官方 `Statistic`；标题必须承载指标文字和单位，固定单位使用英文半角括号且不留空格，例如“账户余额(元)”，`value` 只展示指标值，不能把单位重复放在 `prefix`、`suffix` 或数值内容中。名称、账号等文本型指标同样使用 `Statistic` 的 `title` 与 `value`，不得在组件外手写标签和值来模拟统计项。

**EA-VIS-008** 按钮和表单控件以 `32px` 高度为基准。标准列表使用 Ant Design Table 的中号密度（`size="middle"`），表头和表体单元格内边距统一为上下 `10px`、左右 `16px`（CSS 缩写 `10px 16px`）。表头固定高度为 `42px`，背景使用 `#F5F4F5`，文字颜色使用 `#606266`；表头与表体组成的表格主体外侧统一使用 `1px solid #E4E4E7` 边框。该外边框不得通过开启 Ant Design Table 的全单元格边框模式替代，分页保持在表格主体外。操作列位于最右，文字按钮与操作列左边对齐。字段过多导致表格横向溢出时，表格只在结果模块内横向滚动，操作列必须固定在右侧。金额列的表头和表体必须整体右对齐；同币种金额列默认把单位放在表头字段名后，使用英文半角括号且不留空格，例如“已分账金额(元)”，单元格不重复单位。非人民币单位必须显式声明；混合币种列不得使用固定单位表头，必须逐行显示币种。敏感字段默认脱敏。详情按业务语义分组，不能使用禁用输入框伪装只读信息。

**EA-VIS-013** Shell 的激活页签没有注册或挂载可渲染的页面内容时，内容工作区不得只显示整块灰色背景或空白画布。Shell 必须在内容插槽内渲染一个白色业务面，使用当前内容区的统一外边距、`8px` 圆角且无阴影，并在可用工作区内水平、垂直居中展示 Ant Design Empty。占位状态必须是明确的系统反馈，不得使用装饰性插画、大标题或额外卡片填充空间。

## 响应式与无障碍

**EA-VIS-009** 桌面端以 `1440px` 为基准，推荐最小宽度为 `1280px`。`1440px` 以上使用四列查询布局，`1280px-1439px` 压缩列宽，小于 `1280px` 时查询区降为两列，宽表格只可在结果模块内部横向滚动。核心操作不能被折叠或隐藏。

**EA-VIS-010** 控件必须可通过键盘访问且名称明确。图标工具必须提供可访问名称；焦点、对比度、校验信息和状态含义即使不依赖颜色也必须可辨识。

## 多模块长表单

**EA-VIS-012** 多模块长表单使用灰色页面背景与单列白色业务面组织内容。返回入口位于内容区顶部且独立于白色业务面；内容区不单独渲染页面标题，首个白色业务面直接承载第一个业务模块。各业务模块按填写顺序垂直排列，作为直接同级业务面，模块之间的灰色间距固定为 `16px`，业务面内边距固定为 `16px`，顶部使用 `16px/24px` 模块标题，不嵌套装饰性卡片。字段标签、控件起始位置和必填标识在模块之间保持一致；多行字段由网格统一提供 `24px` 行间距，字段项默认底部外边距归零，模块最后一个字段与业务面底部保持 `16px` 间距，字段默认外边距不得与模块内边距叠加。关联短字段可在同一行排列，上传、长说明和条件联动字段独占整行。页面底部使用固定操作区，操作区具有白色背景和 `1px` 顶部分隔线，按钮组右对齐，次操作在左、唯一主操作在右，间距为 `8px`。表单内容底部必须预留不小于固定操作区高度加 `16px` 的安全距离，确保最后一个字段及其校验信息不被遮挡。

## 视觉冲突规则

**EA-VIS-011** 当组件库默认值与本视觉宪法冲突时，以本视觉宪法为准。已选页面方案中更具体且不违反本宪法的布局规则，优先于本宪法的通用规则。冲突必须在 Change 的假设和评审记录中说明。
