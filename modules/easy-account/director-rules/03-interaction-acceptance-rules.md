# 易账通页面交互与验收规则

## 信息优先级

**EA-INT-001** 按任务依赖关系排列信息：查询列表从查询分类与查询条件、列表标题与全局操作、主要结果、行级或后续操作开始；不使用面包屑、页面标题、标题说明或结果摘要占据列表首屏。分类 Tabs 若决定查询字段，必须与查询条件同属查询模块并位于其顶部；结果区只保留标准列表标题，标题与右侧全局操作水平排列并垂直居中。其他页面族仅在任务确有必要时使用页面标题与口径说明。筛选决定“查什么”，表格负责“比较”，操作只服务于当前行或当前任务。

## 查询与列表状态

**EA-INT-002** 查询必须显示 Loading 并阻止重复提交；提交查询后回到第 1 页并仅刷新列表数据。重置恢复当前分类的默认条件和默认数据集，不影响其他页面状态；展开/收起和分页时必须保留已输入筛选条件。分类共用查询字段时，切换分类保留筛选值；分类使用不同查询字段时，切换分类清除不兼容字段并展示目标分类的默认查询条件，同时回到第 1 页。无匹配结果保留表头与筛选条件；错误状态说明原因并提供重试。查询完成后停留在当前列表，不弹出无关成功提示。

## 页签与空状态

**EA-INT-013** 用户切换到没有注册或挂载页面内容的激活页签时，Shell 必须立即在该页签的内容插槽中展示通用占位状态，不得保留上一页签内容，也不得留下纯灰背景或空白画布。未接入页面使用“页面暂未接入”或“当前页签暂无可展示内容”；只有页面已正常加载且业务数据集为空时，才使用“暂无数据”、“暂无匹配结果”等业务空状态文案。页签切换、关闭和再次打开后，占位状态必须与当前激活页签保持一致。

## 保存与流程状态

**EA-INT-003** 保存前完成校验，失败时定位首个错误字段，提交中禁止重复提交。短任务成功后返回列表并保留可核对摘要，长任务进入结果页；关闭或返回前若有未保存修改必须二次确认。步骤完成后只能进入下一步或明确结果页，不用模糊 Toast 代替关键结果。

## 权限与危险操作

**EA-INT-004** Loading、空、错误、成功、处理中和无权限必须有独立语义。无权限时不渲染可执行操作；敏感字段明文展示需要独立权限；状态不能只靠颜色表达。

**EA-INT-005** 冻结、解冻、调账、关闭和解绑等操作必须二次确认。确认文案必须说明对象、影响和不可逆性；确认期间禁止重复提交，成功后更新目标状态并给出可核对反馈，失败时保留原状态并提供重试或联系路径。

**EA-INT-009** Drawer 的标题必须左对齐，关闭图标必须位于 Header 右侧；Footer 操作必须右对齐。只读详情只保留“关闭”操作，关闭后不得重置来源列表的筛选、分页或滚动上下文。

**EA-INT-010** 多模块长表单的返回入口与“取消”执行相同的离开逻辑：存在未保存修改时必须二次确认，无修改时直接返回来源页。固定底部操作区在页面滚动期间保持可见；提交前校验当前条件下所有可见且启用的必填字段，校验失败时保持已填内容并滚动、聚焦到第一个错误字段。提交期间主按钮显示 Loading，返回、取消和重复提交不可执行；提交成功后进入明确结果或返回来源页并提供可核对反馈，提交失败时保留当前模块、字段值和错误信息。

**EA-INT-011** 整页新增表单在首屏、滚动中段和滚动到底部时，操作区都必须贴合内容视口底部且保持完整可操作；操作区顶部的浅色阴影持续可见，表单最后一个字段、帮助文字和校验信息不得被遮挡。按钮宽度随各自内容和内边距自适应，窗口宽度变化时只调整按钮组位置，不拉伸按钮本身。只要选择整页表单，返回入口与页面标题就必须位于独立通栏标题模块，标题模块和后续信息模块保持 `16px` 垂直间距及 `8px` 圆角。所有 Table 状态列使用带中文文案和语义色的 Tag，切换查询、分页和数据状态后不得退化为 Badge、圆点或纯色文字。

**EA-INT-012** 整页新增表单包含超过 10 个可交互信息项时，模块内字段必须保持标签在上、控件在下；不得因校验错误、帮助文案、条件字段切换或异步回填退化为水平表单。内容工作区不小于 `1200px` 时普通短字段每行 3 项，`768px-1199px` 时每行 2 项，小于 `768px` 时每行 1 项；断点切换只改变字段占列数，不改变字段顺序、必填关系、默认值或业务分组。跨列字段必须从新栅格列起始位置开始并完整容纳标签、控件、帮助与校验信息，不得与相邻字段重叠或造成同行控件错位。

## 响应式与验收

**EA-INT-006** 小于 `1280px` 时查询条件折为两列，表格允许在结果模块内横向滚动；核心查询、重置和行主操作仍必须可见。任何响应式变化不得改变字段含义、金额口径或权限边界。

**EA-INT-007** 下列场景是当前规则的最低验收要求：

| 规则 | 场景 | 通过条件 |
| --- | --- | --- |
| `EA-INT-002` | 正常查询、重置、无结果、`ERROR` 错误 | 四种状态均可见且流程不跳离列表 |
| `EA-INT-004` | 无权限账户 | 不出现冻结、调账等执行按钮，字段继续脱敏 |
| `EA-INT-005` | 点击冻结并取消、确认 | 取消不变更，确认只变更目标行且有反馈 |
| `EA-VIS-009` | `1280px` 与 `1024px` | 查询从四列变两列，表格可滚动，按钮不溢出 |
| `EA-TPL-004` | 分别检查查询字段随分类变化和查询字段固定的 Tabs 列表、标准列表标题、列设置、状态列与分页 | 查询字段随分类变化时 Tabs 位于查询模块顶部，结果模块显示标准列表标题且 Table 上方不重复 Tabs；查询字段固定时 Tabs 可替代结果标题，结果工具栏高度固定为 `32px`；每个标准 Table 的工具栏右侧都有仅图标列设置按钮且可访问名称为“列设置”，操作列不可隐藏；切换后按钮不换行、工具栏不跳动，所有状态值均以带中文文案和语义色的 Tag 展示；分页左侧显示“共 X 条”统计，右侧显示 Ant Design 页码、页大小切换和更多分页控件，切换每页条数后回到第 1 页 |
| `EA-TPL-007`、`EA-TPL-013` | 分别使用 8 项、9–10 项和 11 项信息的新增或编辑任务 | 8 项以内在 Drawer 与整页之间选择时使用 Drawer；9–10 项按业务模块、联动、上传和长说明复杂度选择；11 项使用整页表单，且字段计数不包含纯展示说明、模块标题和系统自动回填字段 |
| `EA-TPL-013`、`EA-TPL-014`、`EA-VIS-012` | 按规则选择整页表单 | 信息模块纵向单列排列，标题为独立通栏模块；直接同级模块间距为 `16px`、圆角为 `8px`；固定底部操作区不遮挡最后字段，按钮右对齐且主操作在最右 |
| `EA-INT-010` | 长表单必填项缺失后提交；修改后返回或取消；重复点击提交 | 定位并聚焦首个错误且保留已填内容；离开前出现未保存确认；提交中不可重复提交 |
| `EA-INT-011` | 在长表单顶部、中段和底部滚动，并分别检查宽屏与窄屏 | 操作区始终吸底且顶部浅色阴影可见；按钮按内容自适应宽度且不等分撑满；最后字段不被遮挡；标题模块、模块间距和圆角保持稳定 |
| `EA-TPL-015`、`EA-INT-012` | 超过 10 个可交互信息项的整页新增表单，在内容工作区宽度 `1440px`、`1024px` 和 `767px` 下展示，并触发必填错误与条件字段切换 | 标签始终位于控件上方；普通短字段依次呈现 3 列、2 列、1 列；字段顺序和业务分组不变；跨列字段、帮助与校验信息完整显示且无重叠、错位或无意义空列 |
| `EA-TPL-014` | 检查 Shell 内的内容工作区外层 | 四个方向的内边距均为 `12px`，页面缩放或状态切换后不回退为 `20px` |
| `EA-TPL-014` | 检查查询、结果、标题和表单分组等直接同级业务模块 | 每个模块四个方向的内边距均为 `16px`，不存在局部 `20px` 内边距造成对齐差异 |
| `EA-TPL-004` | 在查询条件展开与收起两种状态下检查最右侧文字按钮 | “展开/收起”按钮左内边距为 `8px`、右内边距为 `0`；不存在 Ant Design 默认的 `15px` 右内边距，按钮与容器右边界对齐 |
| `EA-VIS-013`、`EA-INT-013` | 切换到未注册或未挂载页面内容的页签，再关闭、重新打开该页签 | 每次都在当前内容插槽中展示白色业务面和居中的 Ant Design Empty；不显示上一页签内容，不出现纯灰背景或空白画布；文案明确为页面暂未接入，不误用“暂无数据” |

## 冲突裁决

**EA-INT-008** 本文件的安全、权限和流程规则优先于视觉与页面方案规则；视觉宪法优先于组件库默认样式。所有无法由规则证明的行为保持 `legacy` 或 `pending`，不得以临时实现绕过策略。
