# Easy Account Component Rules

## Boundary

本文件定义 Easy Account 页面的组件语义。实现时优先使用 Easy Account 实际工程的组件库；未提供工程时，评审预览使用可访问的语义 HTML，不引用 Boss Ledger 组件封装。

## Required Components

- `PageHeader`：页面名称、辅助说明和页面级主操作。
- `FilterForm`：查询条件、重置、查询和展开/收起。默认使用标签在上、控件在下的纵向布局；只有主对象选择器后紧接账户总览的组合，才将该选择器改为标签在左、控件在右的横向布局。桌面端该选择器整体宽度与账户总览第一个 `Statistic` 指标列一致，不能沿用普通选择器的较宽固定列；小于 `768px` 时恢复整行纵向。该规则不能影响同页后续查询条件或不带账户总览的普通筛选。选择器与账户总览之间不显示分割线，账户总览标题上方保留 `32px`。
- `DataTable`：加载、空、错误、列设置、行操作和分页；使用 Ant Design Table 的 `middle` 尺寸，表头与表体单元格内边距为上下 `10px`、左右 `16px`，表头高 `42px`、背景 `#F5F4F5`、文字色 `#606266`，表格主体使用 `1px solid #E4E4E7` 外边框；列标题与字段值默认完整展示，按列宽折行而非省略，操作列和紧凑状态控件可保持单行。金额列的表头和单元格整体右对齐；同币种金额列的单位默认以英文括号追加在表头，如“金额(元)”，单元格只显示格式化数值。
- `Statistic`：账户余额、数量、账户名称、银行账号等对象总览，以及超过 3 条时的查询结果汇总指标，统一使用 Ant Design 官方 `Statistic`。`title` 必须包含指标文字及固定单位，单位使用英文半角括号且不留空格，例如“账户余额(元)”；`value` 只展示数值或文本值，不通过 `prefix`、`suffix` 或值内容重复单位。账号等敏感值保持脱敏。`overview` 服务当前选中对象，位于普通查询条件上方，指标在总览区域内平铺。`summary` 服务当前查询结果：1–3 条时用 `14px` 紧凑文字替换查询列表标题，数值使用主色，全角 `｜` 分隔符使用 `#E4E4E7`；超过 3 条时位于查询条件模块下方、结果 Table 上方，不显示区域标题或外层业务面，每个指标使用 `12px` 间距、`16px` 内边距和 `6px` 圆角的独立白色 Statistic 卡片，不使用边框或阴影。多 Tab 查询页只有部分分类需要总览时，通过 `overview.config.visibleTabKeys` 声明展示总览的 Tab。
- `OverviewManage`：Page Spec 显式声明 `overview.manage` 且提供管理配置时，对象总览标题行默认渲染一个 `32px` 高的管理按钮；仅在具体配置声明 `visible: false` 时隐藏。按钮默认使用 Primary，仅在具体配置声明 `primary: false` 时使用次级样式；点击后使用 Ant Design Modal 承载不超过 6 个可配置字段的新增任务。按钮文案、Modal 标题、字段、选项、校验、初始值、提交文案及反馈由具体产品或业务配置，共享组件不预设领域字段；未声明能力或管理配置时不渲染入口，查询结果汇总不提供管理入口。
- `Tabs`：位于查询业务模块顶部的业务分类 Tabs 使用横向铺满的 `#FBFCFC` 导航面，并在导航区域底部显示 `1px solid #E4E4E7` 分割线；结果列表内用于替代标题的 Tabs 继续遵循结果工具栏规则。
- `Amount`：使用等宽数字特性，同时显示币种和口径。
- `StatusIndicator`：图形或状态点与中文状态文本组合。
- `Form`：支持必填、同步校验、提交中和服务端错误定位。
- `ControlRadius`：所有普通 Button 和有外框的表单交互控件统一使用 `6px` 圆角，覆盖 Input、InputNumber、Select、DatePicker、RangePicker、Textarea、TreeSelect 和上传触发按钮的默认及交互状态。业务模块、Modal、Tag、Radio、Checkbox、Switch 和圆形图标按钮按各自语义或几何规则处理，不套用输入类控件圆角。
- `Dialog` / `Drawer`：Header 左上角必须有非空任务标题，表单 `title` 缺失时回退到触发操作 `label`；同时具备关闭方式、焦点管理和底部操作区。Drawer 使用满高纵向布局，Header 固定、Body 独立滚动、Footer 固定吸底；Header 关闭 icon 右对齐，Body 四边 `24px` 内边距，Footer 操作位于右下角且右对齐，按钮间距为 `8px`，内容区不重复渲染 Header 标题。
- `Result`：显示结果状态、结果说明、关键摘要和后续操作。

## Interaction Rules

- 查询、重置、分页和列设置必须具备可见状态变化。
- 会改变账务结果的操作使用确认对话框，不使用浏览器原生 `confirm` 作为正式交互。
- 主操作、次操作和危险操作使用不同语义，不仅通过颜色区分。
- 缺少权限时展示权限状态，不生成伪造成功结果。
